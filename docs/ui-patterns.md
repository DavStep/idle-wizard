# UI Patterns and Reusable Widget Library

This is the authoritative reusable widget library for Idle Wizard. Before adding UI, map every visible or interactive building block to an entry here and reuse its contract.

## Reuse Rule

- Classify each building block as `reuse`, `extension`, or `new widget` before editing product UI code.
- `reuse` uses a library entry unchanged. `extension` supplies feature data, copy, or composition without changing the entry's visual, interaction, state, or accessibility contract.
- `new widget` includes a new primitive, compound component, scroll behavior, box/dialog type, control pattern, or a meaningfully different variant of an existing entry.
- Before adding a new widget, identify its exact name, purpose, closest existing entry and why it is insufficient, supported states, and intended consumers.
- Implement new widgets as reusable project components and add them to this library with their stable source, contract, and real-app preview evidence.
- Every completed UI task reports `New widgets: none` or lists the widgets introduced.

## Box Construction

- The existing ordinary border-labeled box keeps compact padding, no added shadow, and its current themed frame contract. New default room landmarks and illustrated panels require separately approved image-backed widgets; do not mutate this legacy box into an all-purpose fantasy card.
- In selectable themes, standard `style-box` inner sections use `inner-section-panel-<theme>-9slice.png` with CSS slice order `91 73 90 83 fill`. Its rendered border widths are those same qUIck margins scaled from the `1080px` export width to the `390px` logical surface; never substitute arbitrary compact border widths. Keep the exact center-sample color behind the border image so fractional contain scaling cannot expose transparent hairlines at slice joins. The top panel is the explicit exception and uses the vertically flipped, less-rounded top-panel sibling of the inactive room-tab skin. Do not reuse the inner-section skin for other outer `style-panel` surfaces, dialogs, buttons, tabs, tutorial surfaces, or feature-owned paper art.
- Box titles sit embedded transparently over the top border, without a background backplate.
- Box titles use the shared surface-colored text stroke in every selectable theme, keeping the border visible around the glyphs without creating a rectangular title surface.
- Secondary border labels, such as counts, current controls, actions, and tabs, use smaller normal-weight text centered on the border line.
- Default player-facing popup/dialog boxes use the shared Root Run Expedition dialog shell: fixed `304px` content width and `53px` minimum content height produce the standard `364px` brown outer nine-slice; `352px` Expedition paper nine-slice inset `6px` horizontally, `31px` from the shell top, and `21px` from the compact shell bottom; separate `222x44px` purple title plaque; `41px` round X close asset centered `23px` below the shell; and one compact bottom-right shadow. ## Numbered Rows
