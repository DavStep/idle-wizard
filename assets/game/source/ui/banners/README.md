# Shared banners

Banner assets are named by appearance, not by their first feature consumer.

- `banner-<color>` is the centered, two-ended plaque.
- `banner-<color>-right` is the one-ended plaque that points right.
- `banner-<color>-ribbon` is the centered folded-ribbon silhouette.
- `.9.png` identifies banners that can stretch as nine-slices; fixed-size banners
  keep the ordinary `.png` suffix.

Feature code may keep semantic usage names such as `dialogTitle` or
`researchStationTitle`, but the source texture remains reusable.
