# Root Run Settings UI assets

These assets are copied from Root Run's generated qUIck Settings dialog:

- `settings-knob.png` comes from `asset-6a1edbf4.png` and renders at the qUIck `69 / 3 = 23px` source size.
- `settings-row-bg-9slice.png` comes from `asset-802a0a33.png` and uses source slice insets `13, 17, 25, 19` for left, top, right, and bottom.

The Idle Wizard stall loader reuses these exact assets and the Settings dialog's `/3` layout scale.
