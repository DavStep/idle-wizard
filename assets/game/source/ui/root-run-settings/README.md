# Root Run Settings UI assets

These assets are copied from Root Run's generated qUIck Settings dialog:

- `settings-icon-gear.png` is the exact `property_1_settings.png` gear export from Root Run's top HUD and is the game's only gear icon.
- `settings-knob.png` comes from `asset-6a1edbf4.png` and renders at the qUIck `69 / 3 = 23px` source size.
- `settings-row-bg-9slice.png` comes from `asset-802a0a33.png` and uses source slice insets `13, 17, 25, 19` for left, top, right, and bottom.
- `settings-icon-sound.png`, `settings-icon-music.png`, and `settings-icon-vibration.png` are the exact icon exports used by Root Run's sound, music, and vibration rows.

Idle Wizard reuses these exact assets and the Settings dialog's `/3` layout scale for the device preferences board and trader stall loaders.
