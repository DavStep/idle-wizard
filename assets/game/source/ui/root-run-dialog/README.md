# Root Run dialog chrome

These raster assets preserve the shared Root Run backpack-dialog composition:

- `dialog-title-compact.png`: qUIck compact nine-slice, texture margins
  `left 126`, `top 39`, `right 127`, `bottom 43`.
- `expedition-dialog-close.png`: canonical fixed `122x122` close control shared by
  every Root Run dialog.

The source files are copied byte-for-byte from the sibling `root-run` project.
The shared dialog content panel intentionally reuses
`public/ui/root-run-research/research-card-1000x304.9.png`.
