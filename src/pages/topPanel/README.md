# Top Panel

The top panel is shared room UI. It shows player name, mana, coin, and crystal above each page.

Use the compact player-card composition: the avatar spans the left side and stays grounded to the panel edge; username and currencies share the first row; mana and its `+n/s` rate share the second row; and the compact white/purple level badge sits beside one continuous Root Rush-style request rail. In this panel, resource icons lead their values. Keep mana subordinate to the username and preserve visible vertical separation between username, mana, and the level badge.

The quest rail copies Root Rush's in-game progress geometry in CSS: a full black capsule with a dark inset rim, a 2px total edge-to-fill inset, and a rounded fill without its own outline. The fill uses the selected player progress treatment, including the multicolor gradient, while the outer capsule remains the only frame. Drive the fill's live right edge instead of clipping or scaling it so both end caps stay round at partial progress. Thin ticks divide the rail into one segment per configured request. A partially completed active request fills the matching fraction of its segment, so early-level progress never appears empty while the request is advancing. The level badge uses Root Run's exact main-HUD star asset. Keep the small `Complete N more quests to level up` caption left-aligned directly under the rail with bottom breathing room, without letting the caption shift the rail away from the badge's optical center. Keep the whole quest row hidden at level 0; reveal it only after the automatic transition reaches level 1. Completed requests snap Elara's Request box and send a short three-star flight from its right edge into the level badge. The final request fills the old rail before the badge automatically advances and the next level rail appears. Skip this choreography when reduced motion is requested. Shrink resource text only when it would clip. Mana uses the same vivid blue token everywhere.

The rail frame is drawn directly in CSS. It is simple flat geometry, so rasterizing it into a nine-slice only adds resampling and corner distortion. Keep the frame, fill, and divider state as separate DOM layers. Animate the fill's right edge instead of using `scaleX`, which would squash both capsule caps. The divider immediately after a completed segment is dark; future dividers remain light.

Open the reproducible non-persistent `1 / 4` review state with `/?devUi=topPanelQuestProgress` or `cheats.openUi('topPanelQuestProgress')`. The preview hides the tutorial backdrop without changing tutorial progress, so native-pixel captures preserve the panel's real colors.

The Level-reward dialog reuses Load Stall's split-paper Expedition composition: no continuous paper panel, two full-width instances of the exact dialog paper nine-slice, the standard dialog content column with no added side inset, an `8px` visible paper-to-paper gap, and fixed yellow previous/next buttons inside the lower board corners. All dialog copy is Title Case. Mana and crystal amounts use their atlas icons after the numeric value while retaining accessible resource labels.

Settings open directly to one light Root Run device board containing only the icon-led `sfx`, `music`, and `haptics` rows. Each row uses the shared Root Run compact switch. The real client version and connected user identity sit below the board, with a yellow copy action next to the shortened identity. The Settings surface has no account, report, configuration, or visual-option tab strip. Username prompts, feedback entry, and the avatar picker remain dedicated contextual surfaces rather than Settings options. Pressing the top-panel avatar opens the avatar picker directly; locked choices stay muted silhouettes.
