# Top Panel

The top panel is shared room UI. It uses Root Run's qUIck-authored main-HUD composition above every page. Its background uses `midnight-top-panel-background-9slice.png`, a dedicated less-rounded sibling of the inactive bottom-room-tab skin, flipped vertically and stretched across the full source width from the top edge. The background ends at source y `120`, leaving a `16px` separation before room content begins at y `136`.

Keep the source geometry at `1080px` and map it through the shared `/3` retained-Pixi scale: the HUD root starts at authored `32/32` (`10.67/10.67` source), avatar at the far left, level star and rail centered across the top, three equal currency capsules below the rail, and the square settings button at the far right. Do not retain the reference export's authored `108px` notch offset inside Pixi; `canvas.css` already starts the interactive canvas below `safe-area-inset-top` and fills that external strip with the top-panel color. The three capsules are coin, the page-context currency (crystal by default), and mana. Resource icons lead their values. The username is centered directly under the avatar, and the mana generation rate is centered directly under the mana capsule.

The level rail reuses Root Run's exact level-star, fixed panel, and rounded track assets. Its fill always uses Idle Wizard's purple-to-gold gradient inside the Root Run shape. Thin ticks divide the rail into one segment per configured request; a partially completed active request fills the matching fraction of its segment. Do not render a fraction, remaining count, or other progress number on or under the rail. Keep the whole rail hidden at level 0 and reveal it only after the automatic transition reaches level 1. Completed requests reuse Root Run's one-star research flyout exactly: the retained Pixi path maps its 68px icon, 900px/s speed, and 96px arc through the shared `/3` source scale, holds the rail until arrival, then plays the eight-spark burst and 400ms level-star impact. The final request fills the old rail before the badge automatically advances and the next level rail appears. Skip this choreography when reduced motion is requested.

The retained-Pixi HUD is the production path. Its rail frame uses the copied Root Run qUIck assets, while fill and divider state remain independent graphics layers. The level star and the complete visible progress rail are one press target that opens Level Rewards, with shared press feedback and tap haptics. Animate the fill's right edge instead of using `scaleX`, which would squash both rounded caps. Shrink resource text only when it would clip. Mana uses the same vivid blue token everywhere.

Open the reproducible non-persistent `1 / 4` review state with `/?devUi=topPanelQuestProgress` or `cheats.openUi('topPanelQuestProgress')`. The preview hides the tutorial backdrop without changing tutorial progress, so native-pixel captures preserve the panel's real colors.

The Level-reward dialog reuses Load Stall's split-paper Expedition composition: no continuous paper panel, two full-width instances of the exact dialog paper nine-slice, the standard dialog content column with no added side inset, an `8px` visible paper-to-paper gap, and fixed yellow previous/next buttons inside the lower board corners. All dialog copy is Title Case. Mana and crystal amounts use their atlas icons after the numeric value while retaining accessible resource labels.

Settings open directly to one light Root Run device board containing only the icon-led `sfx`, `music`, and `haptics` rows. Each row uses the shared Root Run compact switch. The real client version and connected user identity sit below the board, with a yellow copy action next to the shortened identity. The Settings surface has no account, report, configuration, or visual-option tab strip. Username prompts, feedback entry, and the avatar picker remain dedicated contextual surfaces rather than Settings options. Pressing the top-panel avatar opens the avatar picker directly; locked choices stay muted silhouettes.
