# Alliance Info Dialog

Shows a read-only popup for a public alliance when an alliance row or tag is pressed. It reuses the Trade Alliance Home split-paper summary and member rows, omitting only the owned-alliance `Membership` row. The alliance identity fills the shared title plaque at the authored size when possible and shrinks proportionally for longer names. The shell footer shows `Join` or `Apply` only when that action is available, shows a disabled gray `Pending` action while the viewer's application remains open, and otherwise has no action.
