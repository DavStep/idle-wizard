# Workshop Page

The Workshop is the first room view.

It sits between Garden and Research. It shows one `Elara's Request` at a time, plus the summon action, bag popup, transient reward flyouts, discoveries, leaderboard, alliance controls, and page name. The request title is a passive label and never opens an information dialog. Completing the final request advances the player level automatically; the progression slot never becomes a separate level-up action. Segmented request progress and the Root Run one-star completion flyout live in the shared top panel alongside mana, coin, crystal, and level. Tutorial guidance never hides or disables the progress row or other Workshop controls. Prestige is its own gated page after level 7. Workshop secondary actions unlock by player level; keep those gameplay gates in page managers and keep gameplay effects behind gameplay/backend facades.

Open `/src/dev/uiRecipes/workshop-request-progress.html` for a non-persistent `1/3` active-request rendering guard that deliberately supplies a stale derived ratio and verifies the presenter keeps the fill synchronized with the visible quantities.

Open `/src/dev/uiRecipes/world-chat-prestige.html` for a backend-free retained World Chat state whose final system row renders the real prestige-star asset as a measured `PixiInlineText` run inside the prestige announcement.

Follow `docs/style.md`: high-contrast text, quiet surfaces, readable Lilita One text, simple non-dialog boxes, one dominant action landmark, and no unowned decoration. Reuse shared row, popup, border-label, and expandable-box patterns from `docs/ui-patterns.md`.

Its arched violet-night silhouette echoes the loading splash while remaining lower-contrast than the summoning circle. It has no input, state, motion, or accessibility contract.
