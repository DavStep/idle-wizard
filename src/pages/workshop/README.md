# Workshop Page

The Workshop is the first room view.

It sits between Garden and Research. It shows one `Elara's Request` at a time, plus the summon action, bag popup, transient reward flyouts, discoveries, leaderboard, alliance controls, and page name. Completing the final request advances the player level automatically; the progression slot never becomes a separate level-up action. Segmented request progress and completion flights live in the shared top panel alongside mana, coin, crystal, and level. The first-run reveal gate keeps that progress row hidden until Elara introduces requests. Prestige is its own gated page after level 7. Workshop secondary actions unlock by player level; keep those gates in page managers and keep gameplay effects behind gameplay/backend facades.

Follow `docs/style.md`: high-contrast text, quiet surfaces, readable Lilita One text, simple non-dialog boxes, and no decorative visuals. Reuse shared row, popup, border-label, and expandable-box patterns from `docs/ui-patterns.md`.

The Workshop side controls form a fixed top stack directly below `Elara's Request`: `Stats` sits in the top-right slot, then the left and right icon columns share one first-row baseline. The `Bag` secondary action is the fourth left-side HUD panel button and uses the dedicated backpack art. Workshop side-control labels use Title Case with white fill and the shared black text stroke. `Inbox` uses a matching warm-brown courier owl holding a rolled message, with smooth fills, compact shadows, and heavy black strokes. `Leaderboard` uses the matching restrained golden, black-outlined trophy art. `Discoveries` uses the matching leather journal, magnifying glass, and gold-corner art. `Stats` uses the shared yellow Root Run button configuration. `Summon Seed` uses an `11px` action label on the shorter cost-button background configuration recolored to the shared info icon's blue/cyan palette, with black-stroked action and cost text plus the shared mana-drop icon and numeric cost on its second row. It swaps to the shared gray cost-button skin while disabled. Other purchase cost buttons stay green and popup tabs stay on the brown selected/deselected skins.

The Bag dialog uses Title Case for its title, category tabs, currencies, and item names. `Currencies` and `Seeds` are always available; `Herbs` appears when Garden unlocks, while `Potions` and `Ingredients` appear when Brewing unlocks. Its retained category tabs keep the shared compact `11px` popup-tab type on the wider frame-attached strip.

The retained `Summoning Seeds` dialog uses Title Case throughout its visible title and content. It uses two paper sections. The top section shows `Auto Summon`, a `Locked` label or the shared Root Run toggle, the continuous `Keep Mana Above` slider with a mana value icon, and the selected seed icon/name with its snapping drop-rate slider. Both use the shared 14px slider rail. The bottom section is the selectable seed list. The drop-rate slider maps `none`, `low`, `medium`, and `high` to empty, red, yellow, and green fill while keeping the exact Root Run Settings knob. Those state names use matching contrast-safe text hues; `none` keeps the normal dialog ink. Every stop remains selectable, and choosing `none` for every seed makes summoning unavailable until one seed is set to an active weight.
