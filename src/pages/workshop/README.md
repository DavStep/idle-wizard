# Workshop Page

The Workshop is the first room view.

It sits between Garden and Research. It shows one `Elara's Request` at a time, plus the summon action, bag popup, transient reward flyouts, discoveries, leaderboard, alliance controls, and page name. The request title is a passive, centered title-only instance of the shared ribbon widget using its compact purple Workshop skin; Workshop renders it at `80.5%` scale, nudges its label `2px` upward inside the skin, and overlaps the request card's top edge slightly so the task row remains the priority. It never opens an information dialog. Pressing a request row navigates to the exact control where it is completed: the Research row, summon control, Garden seed row, Brewing recipe card, Market stall item, or matching Bag item. The destination owns any required tab/dialog selection, scroll centering, and short attention boink; Turn In itself remains the row's inline action. Active progress runs one copied Root Run research shine from left to right toward the reached point, then visually advances the fill after the shine lands and hides it at the far edge. The rail never boinks. Completion holds the outgoing request, lands the shine, fills it to 100%, flies the level star, reveals the next request, and then gives the entire request box one short boink. Completing the final request advances the player level automatically; the progression slot never becomes a separate level-up action. Segmented request progress and the Root Run one-star completion flyout live in the shared top panel alongside mana, coin, crystal, and level. Reduced motion skips the shine and sequencing delay. Tutorial guidance never hides or disables the progress row or other Workshop controls. Prestige is its own gated page after level 7. Workshop secondary actions unlock by player level; keep those gameplay gates in page managers and keep gameplay effects behind gameplay/backend facades.

The production Pixi summon control treats a quick press as one validated release action. Holding an enabled summon waits `100ms`, then repeats every `100ms` while mana and seed-drop eligibility keep each summon successful. Release, cancellation, movement beyond input slop, page deactivation, disabled state, or a failed summon stops the repeat timer; releasing after a repeated hold never adds a final extra summon.
