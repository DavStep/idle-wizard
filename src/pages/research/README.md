# Research Page

Research is the room page immediately right of Workshop.

It renders research boxes from gameplay snapshots. It does not own research costs, completion rules, seed summon filtering, mana effects, summon multipliers, or potion brewing permissions.

Available research prices use the shared cost-button controller and Root Run qUIck cost-button visual: the authored green nine-slice rendered at a compact `281x169` target, Lilita One outlined value, left currency icon, and original content geometry. Unaffordable research keeps the normal card, normal copy, and green button while only the currency amount turns red. Locked research uses dark monochrome card and art-well skins, keeps all copy white, presents the research artwork as an opaque bright monochrome icon, and uses the gray cost button with white outlined `Locked` text plus a compact unlock requirement underneath. Research snapshots provide the formatted cost and `canResearch` state; the page only presents that state and forwards valid presses to `GameplayFacade.buyResearch`.

Each research uses a compact `80px` row while preserving the Root Run station-upgrade card width and nine-slice margins. The left art well is `52x52px`, its artwork is `57px`, the cost/status button is `72x42px`, and completed studies show `Researched` in the shared yellow regular-button skin. Titles and descriptions use the same row ink color. The level badge is reduced to a `0.267` source scale. `ResearchCardSkinManager` sizes each Pixi `NineSliceSprite` from the live DOM geometry so the compact row, well, and badge remain aligned with their CSS fallbacks. The DOM remains responsible for live text, artwork, accessibility, scrolling, and taps. `npm run assets:research-skins` keeps whole-image CSS fallbacks for startup or WebGL failure; those fallbacks disappear only after the Pixi skin layer renders successfully. Idle Wizard intentionally omits Root Run's bottom `current ▶ next` capsule. Category boxes are unframed groups so the card art is never nested inside another panel.

Open `/src/dev/uiRecipes/research-cost-buttons.html` for a non-persistent authored-surface recipe covering the large card layout, selected/deselected research tabs, and free, affordable coin, unaffordable crystal, completed, and locked states.
