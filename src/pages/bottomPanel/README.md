# Bottom Panel

The bottom panel is shared room chrome. It shows the five default room icons in fixed order and reveals optional room tabs only when unlock state makes them visible. Prestige is inserted before the default room list; other optional rooms append after it. Tabs use Root Run's full active and inactive room-tab background assets, fill the full source width, share one bottom baseline, and leave an `8px` source safe gap below the complete tab frame. Unlocked icons remain full-color and full-opacity, with non-selected icons rendered at `1.5x` their base artwork size. Selecting a room applies its existing selected-icon treatment and lifts it `12px` during the retained `205ms` transition. The current room reveals its white Title Case label while inactive tabs remain visually icon-only. Reduced motion snaps directly to the selected geometry. Locked tabs replace the room icon with a larger lock centered lower in the inactive frame. Page facades keep rendering only their room content.

Open the non-persistent visual-QA state with `/?devUi=bottomRoomTabs` or `cheats.openUi('bottomRoomTabs')`. The preview reveals the real bottom chrome without changing tutorial progress or gameplay state. If the app server gate is unavailable, open `/src/dev/uiRecipes/bottom-room-tabs.html?tabs=5` for the same real manager and assets; add `locked=garden` to inspect the locked-tab geometry, or use `tabs=7&current=shop` to verify the selected Market state while unlocked optional rooms remain on the shared baseline.
