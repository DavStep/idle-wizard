# Bottom Panel

The bottom panel is shared room chrome. It shows the five default room icons in the fixed `Brewing -> Garden -> Workshop -> Market -> Research` order and reveals optional room tabs only when unlock state makes them visible. Prestige is inserted before the default room list; other optional rooms append after it. Prestige uses the gold ascension-star medallion at `assets/game/source/icons/icon-prestige-star.png` with `0.9` art scale; do not reuse the crystal currency icon for that room. Tabs use the active theme's matching top-cap nine-slices at `83 91 73 1`: Night uses the unchanged `midnight-room-tab-top-cap.9.png` and selected sibling, while Day uses their exact warm-brown recolors. They fill the full source width, share one bottom baseline, and stretch the shared `26px` lower region to the screen edge with no gap. Each visible-tab count derives one fixed inactive width; the selected tab is always `6px` wider while the row remains edge-to-edge. Unlocked icons remain full-color and full-opacity, with non-selected icons rendered at `1.5x` their base artwork size. When seven tabs are visible, every unlocked icon switches to the shared compact scale (`1.05x` inactive, `1x` selected). Selecting a room applies its existing selected-icon treatment and lifts it `12px` during the retained `205ms` transition. The current room reveals its white Title Case label while inactive tabs remain visually icon-only. Reduced motion snaps directly to the selected geometry. Locked tabs replace the room icon with a larger lock centered lower in the inactive frame. Page facades keep rendering only their room content.

Notification badges reuse the global red/orange notification sprite at the shared
`12px` size. The badge stays inside the tab with `4px` top/right padding, and
retained badges render in a panel-level overlay so a raised
neighboring tab cannot cover them.

Open the non-persistent visual-QA state with `/?devUi=bottomRoomTabs` or `cheats.openUi('bottomRoomTabs')`. The preview reveals the real bottom chrome without changing tutorial progress or gameplay state. If the app server gate is unavailable, open `/src/dev/uiRecipes/bottom-room-tabs.html?tabs=5` for the same real manager and assets; add `locked=garden` to inspect the locked-tab geometry, `notifications=garden,workshop,shop` to inspect the shared red/orange notification placement and overlap, or use `tabs=7&current=shop` to verify the selected Market state while unlocked optional rooms remain on the shared baseline.
