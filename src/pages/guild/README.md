# Guild Page

Guild is the level-15 alternate HUD opened from the Workshop right-side Guild
action. Its bottom HUD replaces room navigation with Workshop, Hall, and
Adventurers, plus locked Fishers, Miners, and World destinations. Each uses
the shared icon-backed bottom-room-tab contract; Workshop returns to the normal room HUD. The Adventurers branch
uses a local Board, Roster, and Log button panel.
It uses ordinary room boxes for hall, board, adventurers, applicants, and log.
Roster separates Adventurers from Applicants with titled Research-card groups;
every person row keeps the Research row height and contain-fits its character.
Log is one newest-first `Chronicle` feed. It keeps up to 80 departures, returns,
paired life events, level-ups, recovery moments, and Guild milestones. Entries
use compact chat-like spacing: character portrait, bold participant name,
right-aligned age, then the event message. Guild-wide system entries use the
Hall icon instead of pretending a character spoke.
All Guild dialogs use the shared Expedition shell, paper content, round close,
and regular-button family. Quest cards reuse the Root Run Settings row skin;
quest details use full-width label/value rows with no Guild-only asset family.
Adventurer cards keep the shared in-shell footer tabs.
