# Visual Settings

Visual settings prices turn profile-only choices into researchable options. White, Lilita One, Root Rush progress bars (stored as `regular`), and the default avatar set (`elara`, `mira`, `bramble`, `corvin`, `juniper`, `rowan`) start researched. Resource icons are fixed on; legacy color-mode values remain profile-compatible but no longer color resource or currency text. Unresearched choices, including zero-cost `free` choices, must be researched from the price label before their name can select the option. The avatar picker is the exception: locked avatars show as silhouettes until another flow marks them researched.
